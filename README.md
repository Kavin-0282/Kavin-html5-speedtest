[怎么用 | How to use]

方式一：直接下载

    点击页面上方绿色 Code 按钮 → Download ZIP
    解压后放置到服务器Apache,nginx，IIS目录上，使用WEB打开 http://服务器IP/index.html

方式二：Git Clone

git clone https://github.com/Kavin-0282/Kavin-html5-speedtest.git

打开文件夹里的 index.html 就行。

    不需要安装任何东西，不需要联网（工具部分），必须具备PHP环境。
